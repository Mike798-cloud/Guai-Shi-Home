# 怪事屋 V10.3｜专业源资产深化终审版

直接打开 `index.html` 可离线运行。本版基于当前完整 `a.zip` 已合入 V10.2 的运行链继续深化，目标不再是增加网页装饰，而是把能在现有工具链中真实制作的源资产升级到运行时会直接使用的几何、材质和声音资源，并继续排查真实点击、状态与降级问题。

## 源资产升级

V10.3 为 `street / office / event-01…20` 共 22 个正式场景生成独立索引网格。每场为 64×36 网格、2304 顶点、13230 个三角索引，带 XYZUV 数据。发布时这些网格和逐场材质参数被处理成 `assets/mesh_v103/mesh-data.js`，由 `index.html` 直接加载，因此不依赖本地 `fetch()` 读取二进制文件；这也保证普通离线打开方式仍能获得 V10.3 网格数据。

每个场景都有单独的 roughness、metalness、wetness、曝光、主光/补光与深度幅度 profile。V10 WebGL 优先使用这些索引网格进行 `drawElements`，同时继续读取 depth / normal / ORM；如果 V10.3 网格不可用，则自动退回旧的深度网格路径，不会阻断游戏。

声音资源也全部换成 V10.3 正式运行集：16 条 Foley、12 条环境底噪、4 条氛围配乐，共 32 条，全部为 **48kHz、立体声、PCM24**。环境与配乐保持可循环设计，Foley 使用多层瞬态/尾响和轻微立体空间差异。WebAudio 优先以 48kHz 创建 context；即使浏览器无法通过 `fetch + decodeAudioData` 读取本地 one-shot，也会使用 `MediaElementSource` 把备用播放接回 FX bus 与声像处理，而不是绕开正式音频链。

## 物理与动画反馈

V10.3 物理层新增障碍 AABB、质量、摩擦、反弹、角速度、旋转阻尼和碰撞事件。事件11的灯具移动会真实受到人物遮挡体限制，并把“灯具撞到人”与“影子延迟”分成两种可观察现象。物件释放后的惯性、旋转和弹簧回位继续保留，低动态模式仍可降低额外运动。

这仍属于网页 2D/2.5D 物理，不会冒充完整 3D 刚体引擎。

## 本轮反复复查中新增发现的 Bug

在完成源资产升级后，真实鼠标专项测试又发现两个并非视觉问题的交互 Bug：事件03售货机和事件18听证桌都属于“容器随光标轻微视差移动、按钮又在容器内部”的结构。连续操作时，按钮会在鼠标按下与抬起之间发生几像素位移，浏览器可能把 `pointerup` 落到父容器，于是玩家明明点了第二个物件，click 却没有触发。

V10.3 将这两个高频操作容器固定到屏幕交互坐标，空间视差仍由 WebGL 场景承担。修复后使用普通 Playwright physical click（非 JS `element.click()`）重复验证：事件03“本人付款→老赵付款→历史小票→双拍售货机”、事件13“停车铃→线路牌→回场地图”、事件18“杯子连续询问三人→切换钥匙再询问”均能稳定解锁结论。

## 最终验证

最终状态机回归可完成 1～20 全部事件，并进入 `current_event=21` 和结局状态；事件20错误证物会拒绝、随后可正确恢复。20 个 renderer 均可实例化、没有重复 DOM ID，页面与 console 错误为 0。

1280×800 全场中心命中扫描未发现新的可见控件遮挡；事件10在包裹打开前隐藏的重建标签仍属于设计性不可交互状态。390×844 触屏、大字号与低动态无横向溢出。

运行资源终审：22 个场景网格及 22 个材质 profile 可解析；88 张 scene/depth/normal/ORM 图全部可解码；32 条 V10.3 音频全部存在且为 48000Hz / 2ch / PCM24；全部实际加载 JS 通过语法检查，唯一生产 CSS 解析错误为 0。

当前沙箱 Chromium 本身仍无法创建 WebGL context，所以不能把 GPU shader / `drawElements` 的真显卡执行宣称为已经实测。这里已经真实验证网格数据解析、WebGL 初始化数据路径以及无 WebGL 时的静态 fallback；正式发行前仍需要在支持 WebGL 的桌面/移动设备补一次 GPU 实机验收。

## 发布处理

当前用户完整包和已有增量仍没有可执行 `.bat/.cmd`，本环境也没有 Windows CMD。因此不会伪造“运行 BAT 成功”。最终交付继续采用此前确认的 `source → release` 等价处理，并且增量 ZIP 只包含相对 V10.2 **本轮真正发生变化且最终运行需要的处理后文件**；不会包含 QA 脚本、音频/网格生成脚本、未引用 manifest 或未修改旧资源。

## 仍然无法诚实抹平的生产上限

V10.3 的几何是从现有深度与正式场景图派生的真实索引网格，而不是专业角色/场景美术重新制作的高低模、UV、烘焙和手绘/扫描 PBR 源工程。场景里的角色也仍然是渲染图组成部分，不具备真正的骨骼、IK、面部和动作树。声音已经成为 48kHz/24-bit stereo 的正式运行资产，但属于程序化重设计/合成，而不是录音棚实录 Foley、真人演奏和商业母带。

因此，本版已经把当前可自动生产的源资产和网页运行链推进到新的上限，但不会把“手工专业3D角色资产、完整3D物理、录音棚声音制作、真实GPU发行设备验收”这些尚未实际完成的项目写成已完成。
